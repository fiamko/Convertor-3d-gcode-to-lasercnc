## English

Download **PrevodnikNC.exe** below and run it directly on Windows x64, including
from USB. No Python install or companion files are required. F1 opens the
embedded English and Czech manuals. Settings and recovery data are created
in `%APPDATA%\UpravaNC_Laser_CNC` on the computer in use.

This release adds CNC milling and depth/feed tests, 1:1 copper/gap comparison
patterns, double-click contour editing with saved selections, faster panning,
a blue original preview and distinct laser/CNC output names. The laser
negative-resist option remains available. The application only creates files;
it does not control a machine. See README and the manuals for limitations.

## Česky

Stáhněte níže **PrevodnikNC.exe** a spusťte přímo ve Windows x64, třeba z USB.
Python ani další soubory vedle EXE nejsou potřeba. F1 otevře vestavěný český
a anglický návod. Nastavení a obnova se vytvářejí v
`%APPDATA%\UpravaNC_Laser_CNC` na používaném počítači.

Verze přidává CNC frézování a test ponoru/posuvu, porovnávací vzor měď/mezera
1:1, dvojklikové úpravy kontur s pokračováním výběru, rychlejší posun,
modrý originál vlevo a odlišené názvy laser/CNC. U laseru zůstává volba
negativního rezistu. Program pouze vytváří soubory a neřídí stroj.
Podrobnosti a omezení jsou v README a návodech.
