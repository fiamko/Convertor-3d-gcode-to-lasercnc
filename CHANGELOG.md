# Changelog / Změny

## 0.6

English:
- Added CNC milling export, marking plunges and a dedicated depth/feed test.
- Unified the comparison pattern at 1:1; retained laser negative-resist selection.
- Added direct double-click exclusion/restoration and resumable contour editing.
- Accelerated copper-distance analysis and canvas panning.
- Restored an unmodified blue input preview; balanced main panels.
- Added project-based laser/CNC output names and expanded GUI regression checks.
- Added a single-file Windows EXE, embedded bilingual manuals and F1 help.

Česky:
- CNC export, značkovací vpichy a samostatný test ponoru/posuvu.
- Jednotný porovnávací vzor 1:1 se zachovanou volbou negativního rezistu u laseru.
- Dvojklik pro vyřazení/vrácení dráhy a pokračování v uložených úpravách kontur.
- Zrychlená analýza odstupů od mědi a posun náhledu.
- Původní modrý náhled vlevo a rovnoměrné hlavní panely.
- Projektové názvy výstupů pro laser/CNC a rozšířené GUI testy.
- Jediný Windows EXE s dvojjazyčným návodem dostupným přes F1.
